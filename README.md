## 文件整理约定

- 同一角色的资料放在同一个角色文件夹中。
- 自制子职按职业分类，保留原始文件名与版本标记。
- 本地导入时与仓库不同的旧人物卡保存在 DND 的历史版本目录中。
- Office 临时锁定文件及系统缓存不纳入版本管理。
